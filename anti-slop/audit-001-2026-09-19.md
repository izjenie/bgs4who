# antislop audit 001 — 2026-09-19

Scope: `index.html` (mirrored BGS4WHO campaign site) plus the Open Graph additions.
Mode: **AFTER** (audit of existing work).
Method: code inspection plus numeric verification. Contrast values were computed from the real
pixels of `assets/vision-cover-01.jpg`, composited with the CSS gradient at the correct
`background-size: cover` scale and `background-position` per breakpoint. Not a browser click-through.

Design Read: candidate campaign landing for WHO Member State delegations and press, in a formal
institutional navy/gold language, dial **ENERGY 2 / RHYTHM 2 / MOTION 1**.

---

## HIGH — Hard Gate

### 1. R-25 — Hero text fails WCAG AA at every breakpoint

Measured minimum contrast across the area each text run passes over:

| Breakpoint | eyebrow (12px) | h1 (large) | lead (22px) | meta (14px) |
|---|---|---|---|---|
| 1440x740 | **3.98** | 5.18 | 6.15 | **3.69** |
| 900x680 | **1.61** | **2.04** | **2.29** | **1.41** |
| 580x680 | **1.74** | **2.37** | **2.08** | **1.41** |

Required: 4.5:1 for small text, 3:1 for large text.

Cause: the gradient falls to `rgba(0,47,95,.28)` at 78%, so the right part of the text column sits
over the light poster. The `<=900px` media query also moves `background-position` to `62% 20%`,
which places the brightest poster area directly under the text. Worst case is the lightest sampled
poster pixel `#8ebcd2` under `rgba(0,47,95,.28)`.

Fix: keep alpha high across the whole text region (desktop) and switch to a vertical dark scrim at
`<=900px` so the poster stays visible only below the text.

### 2. R-02 — Seven em dashes

## MEDIUM — Purpose-Gate

### 3. C-4 / R-35 — Cloudflare challenge script left in the mirror

Line 70 injects `/cdn-cgi/challenge-platform/scripts/jsd/main.js`. That path only exists on
Cloudflare, so on any other host it 404s: one console error and one dead hidden iframe per load.

### 4. R-14 — Identical feature cards

Four `.card` in the leadership section and three `.pillar` in the vision section share size, padding
and layout with no stated hierarchy reason.

### 5. R-06 — `Inter` is never loaded

No `@font-face` and no webfont link, so `Inter` resolves only when installed locally and otherwise
falls back to `ui-sans-serif`. Brand typography is not deterministic across platforms.

---

## LOW — Quality Locks

### 6. R-32 — No explicit focus indicator

No `:focus-visible` rule. The UA default ring is the only indicator and it has weak contrast against
the navy `.button` fill.

### 7. R-37 / R-31 — Direction not written down

No `DESIGN.md`. Dials and the one-line reason for palette, typography and layout are undocumented.

### 8. R-29 — Palette size not declared

Four brand colours (`navy`, `blue`, `sky`, `gold`). Passes as one navy hue family plus a single gold
accent, but that reading is not stated anywhere.
